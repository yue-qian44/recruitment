03 WHAT WE DO

不是“做海报”，
而是建立一整套视觉表达。

从公众号到路演，从现场记录到品牌规范，我们希望把视觉生产做得更系统，也让每一次作品都能留下下一次继续使用的价值。

01 / WECHAT VISUAL

公众号视觉

封面、头图、长图、信息图、版式辅助与栏目视觉。不是“把字放进模板”，而是把内容层级、阅读节奏和品牌识别同时做好。

02 / CAMPAIGN

活动视觉策划

赛事、路演、宣讲与工作室活动的主视觉、海报、展板、现场屏幕与配套物料。

03 / PHOTO

摄影与活动记录

记录路演、调研、人物采访和团队现场，让“发生过”变成可被使用、可被回看的影像资产。

04 / MOTION

视频与动态内容

短视频、活动回顾、人物记录、宣传片段与基础动效，让信息在视频媒介里拥有更好的节奏。

05 / PROJECT

双创项目包装

路演 PPT、成果图表、项目展示与展陈页面。把复杂技术转化成评委、观众和合作方都能快速理解的表达。

06 / SYSTEM

品牌资产沉淀

模板、字体、配色、摄影规范、素材分类与项目归档。让下一次设计不必从零开始。

07 / CSS

把设计感进一步延伸到网页、H5 长页和线上展示界面。通过 CSS 动效、排版节奏和交互细节，让内容不仅“能看”，还更有沉浸感与传播记忆点，也更贴合创新创业表达的线上传播场景。

04 HOW WE WORK

把“临时做图”，
变成稳定的工作流。

真正专业的设计，不只发生在软件里。它从需求澄清开始，到发布后的复盘和归档才结束。

01

接收需求 / BRIEF

先问清楚：给谁看、在哪看、为什么做、核心信息是什么、什么时候交付。

02

共同定调 / IDEA

和采编同步主题、内容结构、主视觉方向与传播节奏，不等文稿全部结束才“补图”。

03

视觉生产 / CREATE

设计、拍摄、剪辑、图表或动态内容制作，让抽象信息变成可感知的画面。

04

联审修改 / REVIEW

一起检查文字、画面、尺寸、版权与信息准确性；修改不是返工，是共同把作品推到更完整。

05

发布适配 / PUBLISH

根据公众号、视频号、路演屏幕、海报输出不同版本，保证每个媒介都“对得上”。

06

归档复盘 / ARCHIVE

保存源文件、照片与成品，总结模板和经验，让一次项目变成下一次的起点。

CLEAR先把问题定义清楚，再开始做。
CO-CREATE内容结构与视觉结构一起生长。
REUSE每次交付，都沉淀下一次可用的资产。

07 BEFORE YOU ASK

你可能会想问，
我们在此回答。

设计部更像一个一起想点子、一起做作品、一起分享参考的地方。不用等到“什么都会”再来，很多能力都能在合作里慢慢长出来。

Q01零基础、还没有做过正式作品，可以报名吗？＋

可以。我们更看重你的兴趣、审美意识和学习意愿，而不是你现在已经会多少。很多同学都是从第一次做封面、第一次排版、第一次跟活动记录开始慢慢成长起来的。

Q02没有项目经历，会不会跟不上大家？＋

不会。我们不只接收“已经很成熟的人”。前期会有学长学姐带着你熟悉工作内容，也会从难度更合适的任务开始，让你在真实工作里逐步建立经验。

Q03平时会不会很忙，会影响上课吗？＋

忙的时候通常集中在活动节点、推文发布前或大型项目阶段，日常不会一直高强度运转。我们会尽量结合课业情况分配任务，重点是稳定参与、按时沟通，而不是无节制加压。

Q04加入之后大概会参与哪些具体工作？＋

主要包括公众号封面与推文配图、活动海报、摄影摄像、短视频剪辑、项目展示包装，以及一些网页/H5 页面表达。不同同学可以先从更感兴趣或更擅长的方向切入。

Q05设计部成员也有机会参与创新创业比赛或项目吗？＋

有。工作室各部门成员都有机会接触项目和赛事，日常分工只是为了协作更清晰。对设计部来说，你既可以做视觉支持，也有机会在项目展示、路演表达和赛事活动中更深入参与。

Q06一定要会AI、Figma、摄影或者剪映吗？＋

不需要。会工具可能是加分项，但绝不是硬门槛。真正重要的是你愿不愿意练习表达、愿不愿意接受修改、愿不愿意主动看参考和吸收反馈。工具可以在实践里慢慢补齐。

Q07如果遇到不会做的任务，会有人带吗？＋

会有。学长学姐会帮你一起梳理需求、看参考、拆思路，也会在修改过程中告诉你为什么这样改。我们希望你不是一个人硬扛，而是在协作里逐渐形成自己的判断。

Q08除了工作本身，部门平时会有别的活动吗？＋

昆冈会有一些比较轻松的交流和团建，比如工作室安排工位、聊灵感、线下聚一聚、参加集体活动等。设计部不只是“接单做图”，也希望大家在相处里建立默契和归属感。

Q09加入工作室后，在学习或生活上也能向学长学姐请教吗？＋

当然可以。除了部门工作，大家也很愿意交流课程、竞赛、大学生活和个人发展上的问题。一个好的部门，不只是教你做图，也会让你在大学里少走一些弯路。

Q10加入设计部，最值得期待的收获是什么？＋

你会得到的不只是几张成品图，而是更完整的表达能力：理解需求、建立审美、完成协作、沉淀作品，也会在一次次真实任务里慢慢拥有自己的风格与作品坐标。

问题可以有很多，但核心其实很简单：你不需要一开始就很厉害， 只要愿意参与、愿意表达、愿意成长，就能在这里找到属于自己的位置。
