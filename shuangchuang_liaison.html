02 / NETWORK QUEST

连接不是随机遭遇，
而是一套任务协议。

每一次外联，都像一次多人协作任务。发出消息只是“接受任务”，真正完成要经过研究、价值判断、具体请求、边界对齐、正确交接和后续维护。

04 / CONNECTION SCENES

真正的联络工作，
发生在不同的剧情场景。

项目需要行业专家

先让项目团队整理真正的问题，再寻找匹配资源。不是把项目书群发出去“求指导”，而是让双方都知道为什么值得见面。

想办一次 AI 分享

先明确听众是谁、希望学到什么，再寻找企业或技术社区；连接建立后，把内容、会务、传播交给对应部门。

学生组织共创

明确双方目标、资源、宣传与执行责任。真正的合作不是海报上多一个 Logo，而是双方都参与创造价值。

邀请往届伙伴回来

一届成员离开校园，不代表关系结束。项目经验、行业认知和组织文化都可以通过长期连接继续回来。

05 / BAD END? GOOD END!

外联也有“坏结局”。
但大多可以提前避免。

BAD ROUTE

“学长您好，有空合作吗？”

没有上下文，没有具体事项，没有时间，也不知道为什么找对方。

VS
GOOD ROUTE

一句话先讲清上下文

身份 + 为什么联系 + 具体事项 + 时间范围 + 希望讨论的下一步。

BAD ROUTE

发完消息无限催

把自己的紧急变成对方的义务，连接很容易在开始之前就失去信任。

VS
GOOD ROUTE

有节奏地跟进

礼貌确认、补充必要信息、给出选择，也接受对方暂时不方便。

09 / LEVEL UP

你练的不是“社交值”，
而是一整套协作能力。

MESSAGE

信息表达

把复杂背景压缩成别人愿意读完、也能马上理解的消息。

JUDGEMENT

关系判断

知道谁真正适合这件事，而不是盲目扩大联系人。

BOUNDARY

边界意识

尊重时间、授权、合作范围与拒绝。

FOLLOW

持续跟进

连接不是发出第一条消息，而是把事情推动到下一步。

VALUE

双向价值

不只问“我们需要什么”，也理解对方为什么值得参与。

HANDOFF

协作交接

让专业的人在正确节点接棒，而不是把所有工作留在自己手里。

MEMORY

关系沉淀

让组织记住合作，而不是每届从零开始找联系人。

COURAGE

主动发信

学会在准备充分后主动开口，也坦然接受没有回复和被拒绝。

10 / JOIN LIAISON

READY TO
CONNECT?

不需要是“社牛”。比热闹更重要的是清楚、可靠、尊重边界，以及愿意把一条线认真接到下一站。

我们希望你带来的

  • 愿意主动沟通，但不冒犯别人。
  • 能把事情说清楚，也愿意认真听。
  • 面对拒绝不会把它理解成个人否定。
  • 对企业、技术社区、学生组织或人与人的协作感兴趣。
  • 答应的事情愿意持续跟进。

你不需要提前拥有的

不需要认识很多企业，不需要自带“人脉”，也不要求性格外向。联系人可以慢慢积累，表达方式可以练，真正重要的是你愿不愿意理解双方、尊重边界，并把连接做得可靠。
