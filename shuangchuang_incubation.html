ABOUT / INCUBATION DEPARTMENT

孵化不是包装，
而是陪一个项目变得真实。

孵化部面向创新创业项目的前端发现与持续培育：从一个还说不清楚的想法开始，帮助团队识别问题、补足证据、链接资源、接受反馈，再把反馈变成下一轮行动。我们关心的不是“材料看起来像不像一个成熟项目”，而是项目本身有没有真的向前走。

02 / ORGANIZATION · HOW WE SUPPORT A PROJECT

不是一个人“带项目”，
而是一套培育协作系统。

围绕项目不同阶段，孵化工作会在课程、项目跟进、赛事训练、资源链接与经验沉淀之间切换。每个模块都服务于同一件事：让团队更清楚自己现在在哪里、为什么卡住、下一步该验证什么。

CORE / PROJECT CULTIVATION

项目培育与持续跟进

记录项目状态，组织阶段沟通，帮助团队把模糊问题拆成可验证任务；在需要时链接课程、导师、赛事和行业资源，并把每次反馈沉淀成下一轮行动。

05 / PROJECT DIAGNOSTIC LAB

先别急着给答案。
先把问题问深一层。

孵化部最重要的能力之一，是项目诊断。一个项目卡住时，原因可能根本不在 PPT，而在问题定义、技术证据、用户理解、价值判断或下一步行动。

PROBLEM

问题

它解决的是谁的什么问题？这个问题是否真实、频繁、值得解决？

“如果不做它，会怎样？”
TECH

技术

现在真正实现了什么？哪些是 Demo，哪些只是未来设想？

“证据在哪里？”
USER

用户

谁会使用？有没有访谈、测试、数据或真实场景支持判断？

“谁真的需要？”
VALUE

价值

相比已有方案，它究竟改变了什么？优势是否可以被验证？

“为什么是你？”
NEXT

下一步

不说“继续优化”，而是明确下一项实验、负责人和判断标准。

“下周具体做什么？”

08 / REAL WORK SCENES

你真正会遇见的，
不是抽象的“创新”，而是一个个现场。

孵化部的工作会随着项目节点改变：有时像编辑，帮团队把逻辑理清；有时像陪练，在路演前不断追问；有时像连接器，把项目带到更合适的人面前。

PROJECT ROOMSCENE 01 / PROJECT CLINIC

项目诊疗室

团队说“用户有需求”，你继续问：访谈了谁？多少人？为什么现在的解决方案不够？真正的孵化往往从一个不太舒服、但很必要的问题开始。

DEMOSCENE 02

模拟路演

计时、提问、记录盲区，把正式答辩可能遇到的问题提前发生。

MENTORSCENE 03

导师交流

提前整理项目状态与关键问题，让有限的交流时间真正解决问题。

COURSESCENE 04

金课现场

把一个值得学的方法组织成同学真正听得懂、用得上的内容。

REVIEWSCENE 05

赛后复盘

奖项之外，更重要的是哪些判断被验证、哪些问题要带回下一轮。

15 / CULTIVATION PRINCIPLE

不替项目成长，
只让成长更有可能发生。

孵化部的价值不在于替团队完成答案，而在于创造足够好的问题、足够真实的反馈、足够合适的连接，以及足够稳定的陪伴。项目最终要靠自己的生命力破茧，也要在一次次琢磨中形成自己的纹理。
