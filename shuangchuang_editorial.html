01 / ABOUT KUN'GANG

先认识昆冈，
再决定什么值得记录。

昆冈众创工作室长期围绕创新创业项目培育、赛事实践、课程与技术交流展开工作。对采编而言，这意味着我们面对的不是“宣传素材”，而是一群正在学习、试错、路演、研发、协作和成长的人。

记录不是给事情镀金。
记录，是让后来的人仍能看见它真实发生过。
PROJECT

项目

比“获得奖项”更值得追问的，是需求怎么被发现、技术怎样迭代、团队在哪一次反馈后改变方向。

PEOPLE

人物

负责人、成员、嘉宾、老师、新人。人的选择与变化，是理解一个创新共同体最直接的入口。

SCENE

现场

路演中的停顿、观众的追问、课程结束后的讨论——很多真正有信息量的内容不在PPT里。

02 / EDITORIAL IDENTITY

采编部不是“写推文的人”。
我们负责发现：这件事到底值得讲什么。

活动与赛事宣传、赛事跟踪、赛后采访是工作形式。核心始终是：到现场、找事实、问人物、核信息、建结构，让没到场的人也能理解发生了什么，以及为什么值得记住。

采风 · 问事 · 秉笔 · 校雠 · 成文 · 藏稿
采风 / FIELD

先到现场

文字开始之前，先观察。空间、动作、表情、声音、停顿和意外，都可能比流程表更接近故事。

问事 / ASK

把问题问到具体

从“有什么感想”走向“哪一次判断后来被推翻”“哪个问题让你答不上来”。

秉笔 / WRITE

让事实自己有力量

少一点套话，多一点证据、人物、场景和变化。写作不是拔高，而是组织真实。

校雠 / VERIFY

核到最后一个名字

奖项、年份、项目名、数据、引语与技术描述，都应该能回到可靠来源。

成文 / EDIT

删掉不需要的句子

结构、节奏、标题和开头都服务于理解。编辑不是把稿子写“华丽”，而是把重点变清楚。

藏稿 / ARCHIVE

让一次采访成为资产

保存录音、照片、原始记录、来源与成稿，让今天的内容成为明天仍可查证的工作室记忆。

03 / WHAT WE REPORT

昆冈有很多故事。
我们决定从哪里切进去。

01 / PROJECT STORY

项目故事

不把项目压缩成一张“喜报”。需求、技术、用户、路演、专家反馈、团队争论和长期迭代，才构成完整故事。

02 / COMPETITION

赛事现场

准备、候场、答辩、追问、赛后复盘。比赛真正有价值的往往不是结果公布那一刻。

03 / TECH

技术解释

金课、开源、AI、企业技术交流，需要有人把术语重新问懂，再翻译给普通读者。

04 / PORTRAIT

人物专访

用一个人的选择、犹豫与成长，让读者看见项目背后的真实劳动。

05 / COMMUNITY

昆冈日常

工位、讨论、训练、团建、深夜改稿。一个组织的文化也藏在不那么宏大的瞬间里。

04 / SIX ANGLES

同一场路演，
至少可以有六种写法。

现场稿

抓瞬间

评委最尖锐的追问是什么？团队在哪一刻停顿？

人物稿

跟一个人

从准备到结束，观察一个项目成员的判断如何变化。

幕后稿

看不见的工作

一场活动如何被办公室、项目、设计、联络等协作完成。

解释稿

回答“为什么”

路演到底评什么？为什么一个项目需要反复讲？

复盘稿

结果之后

团队下一步真正准备改哪三件事，而不只是“再接再厉”。

影像稿

让画面说话

照片与短文字共同保存空间、动作、神态与现场温度。

05 / THE EDITORIAL DESK

一篇内容，
要经过六张桌子。

ASSIGN

选题

给谁看？为什么现在写？真正的问题是什么？

FIELD

采集

采访、观察、影像、数据与现场变化分开记录。

VERIFY

核验

名字、奖项、年份、数字和技术描述回到来源。

FRAME

结构

确定开头、重点、转折和哪些内容应该删掉。

EDIT

编辑

删套话、补证据、校语义，让稿件更准确也更有节奏。

ARCHIVE

归档

保存录音、照片、来源、成稿和可复用内容资产。

06 / INTERVIEW ROOM

别从“获奖有什么感想”开始。

问具体，别替对方回答。
Q01

你们最早的项目版本是什么样？后来为什么推翻？

Q02

哪一次评委、老师或用户的追问最难回答？为什么？

Q03

如果不用任何专业术语，你会怎样解释技术真正解决的问题？

Q04

团队里哪一件最关键的工作最容易被外界忽略？

Q05

你现在最不同意三个月前自己的哪个判断？

Q06

如果没有这场比赛，你们还会继续做吗？

Q07

如果只能给下一届留一句真正有用的提醒，你会说什么？

07 / FIELD NOTE

你的第一次任务：
报道一场“看起来很普通”的金课。

记者手记 / NOTE 001

不要从“为进一步提高……”开始。

试着寻找一个瞬间：
嘉宾停下来想了三秒；
后排同学第一次举手；
一个术语终于被讲懂；
下课后仍有人围着继续问。

故事经常从流程之外开始。

T - 24H

查背景

查嘉宾、主题、技术背景和相关资料，写下三个普通同学真正可能会问的问题。

LIVE

记现场

不要只抄PPT。记录动作、反应、追问、笑声、停顿和那些没有出现在讲稿里的内容。

T + 10MIN

补采访

找一位听众：你来之前怎么理解这个问题？离开时有什么改变？

T + 3H

搭结构

先写最有信息量的一段，再决定背景放在哪里，而不是从活动全称开始。

BEFORE PUBLISH

核事实

人名、职务、课程名、技术概念、照片说明逐项确认。

08 / FACT CHECK

好内容首先要可信。
这是采编最朴素的底线。

NAME

名字

老师、嘉宾、团队、项目全称必须准确。

AWARD

赛事

省赛、国赛、总决赛与奖项级别不能混写。

NUMBER

数字

项目数、参与人数、场次需要可靠来源。

QUOTE

引用

不能为了“更燃”擅自改变采访对象原意。

TECH

技术

没听懂就继续问，不用术语掩盖不理解。

IMAGE

图片

知道人物、时间、地点、活动，照片才真正成为档案。

09 / CONTENT ASSET

发布不是终点。
我们也在为昆冈保存记忆。

同一次采访不必只活在一篇公众号文章里。它可以成为人物长文、短视频脚本、项目案例卡、图片故事、未来招新材料，也可以在几年后帮助后来者重新理解一段历史。

TEXT

文字档案

采访稿、现场笔记、成稿、标题版本与校对记录。

AUDIO

声音档案

经妥善管理的采访录音，让重要表达仍可追溯。

IMAGE

影像档案

照片不仅“好看”，还应拥有时间、地点、人物和事件信息。

SOURCE

来源档案

公开报道、赛事信息与原始数据，支撑未来继续核验。

10 / COLLABORATE

一篇好稿，
很少是一个人关门写出来的。

× DESIGN

与设计部

从选题阶段就判断需要哪些照片、图表、版式、视频或网页表达，而不是成稿后再“找张配图”。

× PROJECT

与项目部

理解项目背景、进度和关键节点，找到真正值得采访的人和问题。

× TALK

与宣讲部

共同拆解复杂赛事和技术内容，让传播准确又易懂。

× LIAISON

与联络部

外部嘉宾与合作活动提前获取准确背景和采访边界。

× OFFICE

与办公室

核对活动流程、组织信息、资料归档和发布节点。

11 / GROW WITH US

从“会写”，
走向“会报道”。

OBSERVE

看见

从流程之外找到真正有信息量的细节。

ASK

提问

不怕暴露自己不懂，问到事情变清楚。

VERIFY

核实

建立事实意识、来源意识和编辑底线。

FRAME

结构

知道什么先说、什么后说、什么应该删。

LISTEN

倾听

采访不是抢话，而是让对方有空间把真正的故事讲出来。

WRITE

表达

用准确、克制、有节奏的文字建立自己的声音。

EDIT

修改

接受一篇稿件被反复推翻，并理解为什么这样改。

ARCHIVE

留下

让今天的报道成为几年后仍然可信、可用的记忆。

12 / JOIN EDITORIAL

COME WITH
CURIOSITY.

文笔当然重要，但我们更喜欢愿意去现场、愿意追问、对细节敏感，也尊重事实的人。

WE HOPE YOU ARE

你可以带着这些来

  • 对人物、项目和“为什么会这样”保持好奇。
  • 愿意采访，也愿意在采访前做功课。
  • 接受修改，甚至接受整段重写。
  • 对名字、数字、引用和来源有一点“较真”。
  • 愿意和设计、项目、宣讲等部门共同完成内容。
YOU DON'T NEED

你不必已经是“成熟写作者”

不会摄影不是硬门槛，没有采访经验也可以从旁听、共同采访和活动记录开始。采编真正训练的是观察、提问、核验、结构和表达——这些都可以在真实工作中长出来。
